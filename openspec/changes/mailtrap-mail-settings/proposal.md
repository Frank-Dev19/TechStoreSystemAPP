# Configuración administrativa de Mailtrap
La API informa el transporte efectivo y la presencia del token. Mostrar el modo Mailtrap cuando corresponda, ocultar campos SMTP y conservar edición de remitentes/mensajes. Solicitar destinatario para la prueba real y no aceptar guardados con token ausente. El token no se ingresa en Angular. Mantener comportamiento SMTP para instalaciones existentes.
Rollback: revertir frontend; el transporte efectivo continúa controlado por backend.
