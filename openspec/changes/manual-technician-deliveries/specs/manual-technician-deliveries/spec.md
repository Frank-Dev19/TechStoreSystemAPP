# Unified internal deliveries UI

## ADDED Requirements

### Requirement: One inventory workspace

The sidebar MUST expose Internal Deliveries under Inventory. One register MUST distinguish order materials and technician supplies using an origin filter.

### Requirement: Manual delivery editor

An authorized inventory user MUST be able to choose an active technician, product and positive quantity, see available stock, and confirm a manual delivery. Serialized and expiring products MUST request their required physical identifiers. Errors MUST remain visible without clearing the form.
