# UI de automatizaciones WhatsApp

## Venta
La interfaz MUST mantener únicamente la orden buscada y MUST enviar un solo identificador al backend.

## Recordatorio manual
La interfaz SHOULD permitir seleccionar equipos elegibles no entregados y confirmar un único envío.

## Fallos finales
La interfaz de supervisor SHOULD mostrar fallos finales y permitir reintento explícito.
