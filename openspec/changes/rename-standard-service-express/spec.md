# Requirements

- `STANDARD_SERVICE` MUST be presented to operators and customers as `Express` or `Servicio express` according to context.
- Express MUST continue to create its quotation directly in the reception wizard without a diagnosis stage.
- Diagnosis and Assembly behavior MUST remain unchanged.
- Existing records and API contracts MUST remain compatible; no enum or database migration is introduced.
- Operational rankings that retain a `standardItemsCount` field MUST label that count as Express.
